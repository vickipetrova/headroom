# Contributing

> Scaffold — written for real in the docs pass (Phase 5).

## Building

macOS 13+ and the Xcode Command Line Tools (`xcode-select --install`). No Xcode project, no
package manager.

```bash
./build.sh          # -> build/Headroom.app
./build.sh --dmg    # also builds build/Headroom.dmg
```

## Ground rules

- No new dependencies.
- Never log or commit tokens.
- Small PRs, one change each.
- Be decent to each other. Disagree about code, not about people.
